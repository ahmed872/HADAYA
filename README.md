# دار التميز للهدايا والدروع — موقع عرض

موقع عربي (RTL) متجاوب لنشاط دروع التكريم والجوائز وهدايا الشركات. واجهة عرض وكتالوج فقط: بلا سلة أو دفع أو حسابات، وكل الطلبات تتم عبر واتساب.

**التقنيات:** React 19 · Vite · Tailwind CSS v4 · Lucide · خطوط عربية مستضافة محلياً (Amiri, IBM Plex Sans Arabic, Aref Ruqaa).

## التشغيل

```bash
npm install
npm run dev          # بيئة التطوير
npm run build        # نسخة الإنتاج (البيانات الفعلية) → dist/
npm run build:demo   # نسخة معاينة ببيانات تواصل تجريبية → dist-demo/
```

مجلد `dist/` جاهز للرفع على أي استضافة ثابتة (Netlify, Vercel, GitHub Pages, cPanel). المسارات نسبية، لذلك يعمل الموقع من أي مجلد.

## تعديل بيانات النشاط

كل البيانات في ملفين فقط:

| الملف | المحتوى |
|---|---|
| `src/config/site.js` | اسم النشاط، رقم الجوال وواتساب، العنوان، مواعيد العمل، الخريطة، التقييم، روابط القائمة |
| `src/data/catalog.js` | الأقسام، المنتجات، معرض الأعمال، القطاعات، المميزات، خطوات العمل |

- **الاسم:** `brand.name` و`brand.shortName` (الاسم الحالي مؤقت للعرض).
- **واتساب:** `whatsappNumber` بالصيغة الدولية بدون `+` (مثال: `9665XXXXXXXX`). كل أزرار الطلب تستخدمه تلقائياً مع رسالة جاهزة باسم المنتج.
- **الخريطة:** `map.embedUrl` و`map.directionsUrl`.
- **ملاحظة الصور التوضيحية:** عند إضافة صور الأعمال الفعلية اجعل `showDemoImageNotice = false`.

## الصور

صور المنتجات الحالية نماذج ثلاثية الأبعاد مصيّرة (Blender Cycles) لأغراض العرض فقط، وتُستبدل بصور المنتجات الفعلية:

1. ضع الصورة الأصلية (jpg/png/webp) في `assets-src/` **بنفس اسم الصورة** التي تريد استبدالها (مثال: `p_wood.jpg`)، أو باسم جديد ثم استخدم الاسم في `catalog.js`.
2. شغّل `npm run images` لتوليد مقاسات WebP المتجاوبة في `public/images/` وتحديث `src/data/images.json`.

يُفضّل أن تكون صور المنتجات بنسبة 4:5 وعرض 1000px على الأقل، وصورة الواجهة `hero` بنسبة 16:9 مع ترك الجهة اليمنى أهدأ لظهور النص.

سكربتات توليد الصور ثلاثية الأبعاد موجودة في `tools/render/` للرجوع إليها.

